# 稀有诡计标签核对清单

> 本文件由 `npm run audit:checklist` 生成，用于人工抽查标注准确性。

诡计标签权重为 **3.0**，是推荐算法的第一优先级，因此标错的代价很大。
这里只列出**数量少、指向具体**的那几个——它们一旦标错，会把两本毫不相干的书强行拉近。

相对地，「红鲱鱼」（77% 的作品）与「心理误导」（61%）属于泛化标签，
出现率过高、区分度低，引擎已把出现率 >70% 的标签自动识别为**背景标签**、不参与相似度计算。

**发现标错的，告诉我 `id` + 标签即可。**
