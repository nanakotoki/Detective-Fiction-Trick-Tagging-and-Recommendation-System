# ICP 备案指南（阿里云 · 北京 · 个人 · 轻量应用服务器）

> 适用情形：域名 `tokei-detective.top`（已实名认证）、服务器为阿里云**轻量应用服务器**、
> 地域**北京（中国内地）**、备案主体为**个人**。
>
> 一句话原理：中国大陆的服务器，**域名要对外提供网站服务必须先备案**；
> 没备案时阿里云的网关（响应头里的 `Server: Beaver`）会把域名请求拦成一个
> 「Non-compliance ICP Filing」页面。用 IP 访问不受影响。

---

## 1. 三个前提条件（先自检，不满足就得先补）

| # | 条件 | 怎么确认 | 不满足怎么办 |
|---|------|----------|--------------|
| 1 | 域名已完成**实名认证**，且认证通过 ≥ 1 天 | 域名控制台 → 域名列表 → 状态「正常」 | 没实名 → 立即提交身份证认证 |
| 2 | **域名持有者 = 备案主体本人**（身份证必须是同一个人的） | 域名列表 → 持有者（通常显示为「**庆」） | 不一致 → 先做域名过户，再备案 |
| 3 | 轻量服务器**剩余有效期 ≥ 3 个月**，且状态为「运行中」 | 轻量控制台 → 实例详情 → 到期时间 | 不足 → **先续费**，否则申请不到备案服务码 |

> ⚠️ 第 2 条最容易翻车：很多人用家人/朋友的身份证买的域名，结果备案被驳回。
> 域名持有者、备案主体、手机号实名，这三者**必须是同一个人**。

---

## 2. 需要准备的材料

- **身份证**原件（要拍正反面，四角完整、无反光、不遮挡）
- **本人实名手机号**（审核期间必须保持畅通 —— 阿里云和管局都可能打电话核实，**没接到电话可能直接驳回**）
- **常用邮箱**（接收备案进度通知）
- **应急联系人**姓名与手机号（部分地区要求）
- **服务器与域名**（上面第 1 节的三个条件）

---

## 3. 备案服务码怎么拿

备案系统里填到「云服务」那一步时，会让你选择服务器并填**备案服务码**：

- 路径一：**轻量应用服务器控制台 → 实例详情 → 「备案」页签**（或实例右侧「更多」菜单里找「备案服务码」）→ 申请/查看服务码。
  每个轻量实例一般有 **5 个**免费服务码名额。
- 路径二：直接在 **阿里云 ICP 代备案管理系统**里选择云服务，系统会自动列出你名下的实例。

> 如果提示「实例不满足备案条件」，99% 是**剩余时长不足 3 个月**，去续费即可。

---

## 4. 填表逐项指南（最容易卡住的地方）

### 4.1 主体信息（个人）

| 栏目 | 怎么填 |
|------|--------|
| 主办单位性质 | **个人** |
| 姓名 / 证件号 | 与身份证完全一致 |
| 证件住所 | 身份证上的地址（照抄，别简写） |
| 手机号 | 本人实名号，**审核期间别关机、别静音** |
| 邮箱 | 常用邮箱 |

### 4.2 网站信息

| 栏目 | 怎么填 | 说明 |
|------|--------|------|
| 网站域名 | `tokei-detective.top` | 填主域名即可；`www` 一般随主域名一起备案。**不要**在同一个网站下堆多个不相关的域名 |
| 网站名称 | `嘉庆的读书笔记` 或 `个人读书笔记` | **3 个以上汉字**，不能纯英文、不能含「中国/中华/国家/政府」、不能含企业名或行业通用词（「XX网」「XX门户」「XX论坛」这类容易被驳回） |
| 网站服务内容 | 个人 → 选 **「其他」**（或「个人空间/博客」） | 别选新闻、出版、教育、医疗、文化等需要**前置审批**的类别 |
| 网站简介 / 备注 | 见下方模板 | 这段文字管局真的会看 |
| 网站负责人 | 与主体一致（个人备案就是你自己） | |

### 4.3 网站简介模板（可以直接抄）

> 本人用于记录和整理个人阅读推理小说的读书笔记，包括书籍基本信息、
> 诡计类型标签整理与个人阅读清单。**非经营性网站**，不提供任何图书全文阅读、
> 电子书下载或在线出版服务，不涉及新闻采编与用户上传内容。

**为什么要这么写**：本项目的知识库里就有"凶手／核心诡计／结局"这类字段，
如果简介里出现「在线阅读」「电子书」「文库」「全文」这类词，很容易被要求提供
《网络出版服务许可证》——个人是拿不到这个证的。**简介必须体现"个人笔记、非经营、不提供内容下载"。**

### 4.4 前置审批

出现下列内容才需要前置审批（个人基本办不下来，**务必避开**）：
新闻、出版、教育、医疗保健、药品和医疗器械、文化、广播电影电视节目。
→ 所以网站名称和简介里**不要**出现「文库」「电子书」「在线阅读」「小说站」等字眼。

## 5. 人脸核验与提交

1. 资料填完后，系统生成**真实性核验**环节；
2. 手机装 **阿里云 APP** → 登录同一账号 → 扫备案页面上的二维码 → 按提示做点头/眨眼等动作；
3. 核验通过后提交，进入阿里云初审。

---

## 6. 三个审核阶段 + 短信核验（**最关键、最容易错过**）

| 阶段 | 时长 | 你要做什么 |
|------|------|-----------|
| ① 阿里云初审 | 1～2 个工作日 | 保持手机畅通；资料有问题会打电话/短信让你改 |
| ② **工信部短信核验** | **收到后 24 小时内必须完成** | 手机会收到工信部短信，**必须在 24 小时内**按短信里的链接/提示完成核验；**超时＝本次备案作废，要重新提交** |
| ③ 管局审核 | 一般 **7～20 个工作日**（北京常见 5～10） | 等待；期间可能电话核实，**务必接听** |

> ② 是最多人栽跟头的地方：短信看着像垃圾短信被忽略，24 小时一过就白等一周。

---

## 7. 备案成功后的四件事

1. **域名解析生效**：云解析里给 `@` 和 `www` 各加一条 A 记录指向服务器公网 IP。
   备案通过后，阿里云的拦截页会自动消失。
2. **网站底部展示备案号**：工信部要求把备案号（如 `京ICP备2026xxxxxx号-1`）
   展示在网站页脚，并链接到 `https://beian.miit.gov.cn`。→ **这一步我来改代码。**
3. **公安联网备案**：ICP 备案通过后，多数地区要求在 **30 日内**到
   「全国互联网安全管理服务平台」（`www.beian.gov.cn`）做公安备案，拿一个公安备案号。
4. **签 HTTPS**：加 `^~ /.well-known/acme-challenge/` 豁免段 → 宝塔一键 Let's Encrypt →
   开强制 HTTPS。→ **这一步我来带你做**（顺序不能错，见 `宝塔路线.md` 第六步）。

## 8. 常见驳回原因（照着避坑）

| 驳回原因 | 怎么避免 |
|----------|----------|
| 网站名称不合规（含企业名、行业词、纯英文） | 用「XX的读书笔记」这种中性个人名 |
| 网站内容与备案信息不符 | 简介如实写；上线后别突然变成"小说在线阅读站" |
| 手机号非本人实名 / 核实电话没接 | 用本人号，审核期全程开机 |
| 域名持有者与备案主体不一致 | 域名过户到本人名下 |
| 服务器剩余时长不足 3 个月 | 先续费 |
| 同一主体短期大量备案 | 一次只备这一个域名 |
| 网站已开通访问 | 备案期间保持域名被阿里云拦截的状态即可（正常现象） |
| 24 小时内未完成短信核验 | 收到短信立刻做 |

## 9. 时间线预估（心里有数）

```
Day 0      提交资料 + 人脸核验          （30 分钟）
Day 1–2    阿里云初审                    （等）
Day 2–3    工信部短信核验                （24 小时内完成，5 分钟）
Day 3–20   北京管局审核                  （等，通常 5–10 个工作日）
────────────────────────────────────────
合计       约 1～3 周
```

**期间网站照常可用**（用 IP 访问 + 密码），不用等备案。

---

## 10. 三条提醒

1. **备案是免费的**。阿里云代备案不收费；任何"加急代办""包过"都是骗局，而且可能被管局注销。
2. **备案期间别改域名持有者、别过户、别换服务器**，会中断流程。
3. 备案号下来后，**每年**要留意阿里云的备案信息核验通知（一般是邮件/短信），
   不响应可能被**注销备案**——注销后域名立刻被拦。
