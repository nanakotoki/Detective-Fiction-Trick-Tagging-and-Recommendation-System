# 备案通过那天：照着做（顺序不能换）

> 前提：ICP 备案审核通过、拿到备案号。
> 全程大约 30 分钟，其中真正需要动脑的只有第 2 步（不做的后果是证书签不下来）。

---

## 0. 先确认真的通过了

- 收到阿里云通知（短信/站内信），**备案控制台**里状态变成「已备案」；
- **记下备案号**，形如 `京ICP备2026xxxxxx号-1` —— 第 7 步页脚要用；
- 管局通过后，工信部系统同步可能有几小时延迟，不影响下面的操作。

---

## 1. 加 A 记录（云解析 DNS）

控制台搜「云解析 DNS」→ 域名解析 → `tokei-detective.top` → 解析设置 → 添加记录：

| 主机记录 | 记录类型 | 解析线路 | 记录值 | TTL |
|---|---|---|---|---|
| `@` | A | 默认 | 服务器公网 IP | 10 分钟 |
| `www` | A | 默认 | 服务器公网 IP | 10 分钟 |

**验证**（Windows）：

```powershell
nslookup tokei-detective.top 223.5.5.5
```

期望：解析出你的服务器 IP。然后浏览器打开 `http://tokei-detective.top/`：
**阿里云那个「Non-compliance ICP Filing」拦截页应当消失**，变成弹出用户名/密码框。
（若还显示拦截页：等 10 分钟，用无痕窗口再试——缓存和 DNS 都可能有延迟。）

---

## 2. ⚠️ 先加 ACME 豁免段（**必须在签证书之前**）

宝塔 → 网站 → 站点设置 → **配置文件**，在 `server { … }` 里加：

```nginx
location ^~ /.well-known/acme-challenge/ {
    root /www/wwwroot/tokei-detective.top;
    auth_basic off;
    allow all;
}
```

保存。

**这一段同时避开两个坑**（两个坑都会让证书签不下来）：

| 少写了什么 | 会怎样 |
|---|---|
| 少 `^~` 这一段 | 校验文件被反向代理转给 Node → **404** |
| 少 `auth_basic off;` | 校验文件被整站密码挡住 → **401** |

**验证**：浏览器无痕窗口打开

```
http://tokei-detective.top/.well-known/acme-challenge/test
```

期望结果是 **404**（不是 401）。404 说明"这个路径既不经过反代、也不要求密码"，正是我们要的。

---

## 3. 签证书

宝塔 → 网站 → 站点设置 → **SSL** → **Let's Encrypt**：

1. 勾选 `tokei-detective.top` 和 `www.tokei-detective.top`；
2. 验证方式选 **文件验证**；
3. 点「申请」，等十几秒。

成功后**先别开强制 HTTPS**，先做第 4 步验收。

> 失败时：日志在站点设置 → SSL 页面里，或 `/www/wwwlogs/tokei-detective.top.error.log`。
> 最常见原因就是第 2 步没做。

---

## 4. 验收（Windows）

```
cd C:\Users\时嘉庆\github\Detective-Fiction-Trick-Tagging-and-Recommendation-System
node deploy/check-deploy.mjs tokei-detective.top tokei:你的密码
```

**期望**：最后一行「失败 0 项」。
域模式会比本机模式多 3 项（HTTP 跳转、证书有效期、HSTS 在位）——**HSTS 那一项能过，
说明反代确实把 `X-Forwarded-Proto: https` 传给了 Node**。

> 忘了带密码的话，脚本会直接告诉你"站点启用了整站密码，请带上凭据重跑"，不会给你一片红。

---

## 5. 开强制 HTTPS

宝塔 → 站点设置 → SSL → 打开 **「强制 HTTPS」**。

⚠️ 开了之后，用 `http://服务器IP/` 访问也会被跳到域名。**这是正常的**，
以后统一用 `https://tokei-detective.top/` 访问。

---

## 6. 换成正式密码

到现在为止用的是临时密码（`Tokei2026Read`），而且之前一直是 HTTP 明文传输。
上了 HTTPS 之后换成你自己的正式密码 —— **在服务器上**跑：

```bash
HASH=$(openssl passwd -apr1 '你的新密码')
echo "tokei:$HASH" | sudo tee /etc/tokei-archive.pass
```

**不需要重载 Nginx**：它每次请求都重新读这个文件，改完立刻生效。
用无痕窗口验证一次（旧密码应当失效）。

---

## 7. 页脚加备案号（这一步我来改代码）

工信部要求：网站页脚展示备案号，并链接到 `https://beian.miit.gov.cn`。

**把备案号发我**（例如 `京ICP备2026xxxxxx号-1`），我改 `web/` 下的页脚，
然后只需重新上传改动的文件 —— **不用重启服务**（前端是静态文件，Node 直接读盘发的）。

---

## 8. 30 天内：公安联网备案

ICP 备案通过后，多数地区要求在 **30 日内**到 **全国互联网安全管理服务平台**
（`www.beian.gov.cn`）办"公安联网备案"：

1. 注册/登录 → 新增网站备案；
2. 主办单位信息（与 ICP 备案一致）；
3. 网站信息（域名、服务器 IP、接入商选阿里云）；
4. 提交后等审核，拿到**公安备案号**（形如 `京公网安备 11010502xxxxxx号`）。

拿到后同样告诉我，我一并放到页脚。

## 出问题速查

| 现象 | 先看哪里 |
|---|---|
| 域名还是显示阿里云拦截页 | A 记录是否生效（`nslookup`）；是否只是缓存（换无痕窗口） |
| 证书申请失败 | 第 2 步的豁免段做了吗；80 端口是否可达；DNS 是否已生效 |
| 申请成功但浏览器报证书错误 | 是否用了 `www` 而证书只签了主域名 |
| 打开是 502 | 后端没跑：`sudo systemctl status trick-archive --no-pager` |
| 打开是 403（非拦截页） | 宝塔站点配置里的规则被改过；`sudo nginx -t` 看语法 |
| 忘了密码 | 重跑第 6 步的命令；或删除 `/etc/tokei-archive.pass` 后重载 |
| 想临时停站 | 宝塔 → 网站 → 站点 → 停用；或 `sudo systemctl stop trick-archive` |
